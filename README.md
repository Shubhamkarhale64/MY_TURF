# 🏟️ MY TURF – Online Turf Booking System

### A Web-Based Platform for Searching and Booking Sports Turfs

## 📌 Project Overview

MY TURF is a web-based application developed using Python and Django. It helps users search for sports turfs and provides an online platform for turf booking and management.

The system aims to make turf searching and booking easier through a simple and user-friendly interface.

## 🚀 Key Features

- User Registration and Login
- User Authentication
- Turf Management
- Online Turf Searching
- Location-Based Turf Search
- Turf Owner Management
- Database Integration

## 🛠️ Technologies Used

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/Shubhamkarhale64/MY_TURF.git
```

2. Open the project folder:

```bash
cd MY_TURF
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the virtual environment:

```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Apply database migrations:

```bash
python manage.py migrate
```

7. Run the development server:

```bash
python manage.py runserver
```
